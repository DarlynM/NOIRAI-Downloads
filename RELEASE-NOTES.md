# Noir for Windows

## Windows 1.13.0

Open **Tools** in chat or the sidebar. Search the directory, add Calculator, World Clock or Text tools, and choose which tools a model can use. Custom local MCP connections and selected-window computer assistance use the same review controls.

Switch models inside a chat or project. The cloud sharing preview lets you include specific earlier local messages. Cloud tool requests show their proposed action and keep the result on your PC until you review sending it back. Chat history jumps to an earlier turn. Run log shows recorded steps and results. Models can ask a question with selectable answers and a free-text option.

## Windows 1.12.2

Open **Receiving desk** in the sidebar to reconcile two deliveries. Rename items, edit the quantities, add or remove rows, and copy a calculated result. The worksheet saves your edits on this PC. It works before your first model download. In local Chat, Noir can also calculate a structured receiving request and update a previously calculated shipment.

The Windows package now ships current version information and instructions. The phone privacy notice explains both pairing choices. Windows publisher signing and broader device testing are funding goals. iPhone and iPad 1.12.1 (20004) remain on their own Apple release schedule.

## 1.9.5

Open Cloud chat and select OpenAI, Claude, Gemini, Mistral or OpenRouter. Enter a key, choose from the models returned by that account and continue in the same chat. Noir shows the destination, API quota and message history before each send. Private turns stay on the PC. Any text you type or paste into the outgoing message goes to the provider.

Local chat, coding tools and provider connections are free in Noir. Each API provider sets its own prices and limits. OpenRouter also supports its existing credits sign-in. Personal ChatGPT, Claude and Gemini subscription access is deferred.

Settings now includes a quiet **Support Noir** entry for voluntary funding and team setup inquiries. These are optional.

Download the Windows x64 installer. Setup needs internet for the verified runtimes. Models download separately. For an in-app update, also download the matching signed update receipt. Windows Authenticode signing is pending. The iPhone app has a separate release cycle.
