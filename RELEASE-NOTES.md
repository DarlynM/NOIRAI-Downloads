## 1.9.5

Open Cloud chat and select OpenAI, Claude, Gemini, Mistral or OpenRouter. Enter a key, choose from the models returned by that account and continue in the same chat. Noir shows the destination, API quota and message history before each send. Private turns stay on the PC. Any text you type or paste into the outgoing message goes to the provider.

Local chat, coding tools and provider connections are free in Noir. Each API provider sets its own prices and limits. OpenRouter also supports its existing credits sign-in. Personal ChatGPT, Claude and Gemini subscription access is deferred.

Settings now includes a quiet **Support Noir** entry for voluntary funding and team setup inquiries. These are optional.

Download the Windows x64 installer. Setup needs internet for the verified runtimes. Models download separately. For an in-app update, also download the matching signed update receipt. Windows Authenticode signing is pending. The iPhone app has a separate release cycle.
